## 如何覆蓋原站

1. 保留原站檔案備份。使用者收藏本來儲存在各自的瀏覽器，不在主機 HTML 裡。
2. 先上傳整個 `assets/`，以及 `favicon.ico`、`manifest.webmanifest`。
3. 最後覆蓋 `index.html`。包內另含 `index .html`，保留這次附件原始檔名的相容入口；兩個入口內容相同，請不要只上傳 HTML。
4. 到原站重新整理。若瀏覽器仍顯示舊版，可強制重新整理；無須清除網站資料。
5. 開啟「收藏」確認原有內容，並檢查搜尋、發音與例句。入口引用的 CSS/JS 都附內容雜湊版本，降低舊快取混用的情況。

若原本公開入口另有名稱，例如 `dictionary.html`，將 `index.html` 複製為原入口名稱，和 assets 一起放在同一目錄即可。不要把網站搬到額外一層資料夾再期待原網址自動改變。`tests/`、README 與 TEST_REPORT 僅供維護，不影響網站執行。

## 舊收藏與進度如何保留

收藏 key **完全不變**：`gsat-standalone-favorites-v1`。
格式也不變：JSON 字串陣列，例如 `["challenge","a/an"]`。6,012 筆原始詞條逐欄比對一致，沒有替換單字 ID，也不會在啟動時清空或重寫收藏。

收藏及使用者進度儲存位置維持原樣；AI 衍生索引改版：

| 資料 | 原有 key／位置 |
| --- | --- |
| 收藏 | `gsat-standalone-favorites-v1` |
| 搜尋偏好 | `gsat-v2-search-feedback-v1` |
| 搭配練習統計 | `gsat-v2-collocation-practice-v1` |
| 最近搜尋 | `gsat-v3-recent-searches-v1` |
| 複習排程 | `gsat-v3-review-queue-v1` |
| AI 索引 | IndexedDB `gsat-ai-search-v1`，key `gsat-v5.1-minilm-l12-6012-exam-636-v1` |

AI 索引內容包含搭配文字，本次變更 key 讓使用者下次啟用 AI 時依新增內容重建索引；這不會清除收藏、複習、練習統計或 API 快取。

保留條件是**相同瀏覽器／使用者設定檔，以及相同 origin：通訊協定、主機名稱與連接埠**。路徑本身不決定 localStorage；但 HTTP 換成 HTTPS、www 換成非 www、換網域或換瀏覽器，都不是同一個儲存空間。參考 [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)。

新版加入「匯出收藏／匯入收藏」。匯入採合併，不刪掉現有收藏，也保留不在現行詞表中的舊字串。一般同站覆蓋不需要匯入。若要搬網域，可先在舊網域部署本版並匯出收藏，再到新網域匯入。這個 JSON 備份只含收藏；複習與練習進度仍保存在原瀏覽器。

直接以 `file://` 開啟檔案時，各瀏覽器的儲存行為不同，不能保證原單檔的本機收藏自動移轉；原本部署在網站上的情況適用上述同源保留規則。

## API 載入改善

- 詞表、釋義、搜尋與收藏仍由本機資料提供。
- 音標／發音、例句、近義詞與搭配各自更新，不必等最慢 API 與翻譯全部完成。
- DictionaryAPI 與 Tatoeba 優先。若不足兩個適合的例句，才請求 FreeDictionaryAPI／Wiktionary；主來源較慢時，650 ms 後按需要啟動備援。
- 先顯示英文例句，定案後才為最多兩句補上翻譯；原有繁中例句翻譯直接沿用。單字補充翻譯改為按需載入。
- 真人發音有主來源時先提供播放；更多口音按需取得。主來源沒有可播放音檔時自動備援，仍可用裝置語音。
- 同 URL 請求合併；全域最多 6 個、每個主機最多 2 個同時請求。共用請求只有在所有使用者都取消後才中止。
- 切字取消舊請求並檢查請求代號，避免 A→B→A 時被較晚完成的舊結果蓋掉。
- 一般請求逾時 4.2 秒；備援／搭配 3.5 秒；翻譯 3 秒。HTTP 429／503 會依 Retry-After 暫緩同主機請求（5–60 秒），不自動密集重試。
- 成功 API 回應另存在 `gsat-online-cache-v5` IndexedDB，不佔用收藏 key。字典與句庫快取 7 天、Datamuse 1 天、翻譯 30 天、404 空結果 5 分鐘；失敗和取消的請求不快取。
- API 磁碟快取最多 300 筆、記憶體快取最多 180 筆；完整單字結果最多 60 筆。磁碟受限時退回記憶體，收藏不受 API 快取整理影響。
- 收藏只更新按鈕與列表，不再重建單字卡或重送 API。搜尋有 90 ms 防抖、中文輸入法處理、結果快取與分批預建 BM25 索引。

這些改動減少不必要等待與重複請求；不代表第三方服務本身的網路延遲變短。首次開站仍須載入獨立詞表。未加入 service worker，因此不保證斷網後首次開站或重新整理可用；已開啟頁面的內建功能可繼續使用。

## 例句挑選

先檢查整字／片語與變化形、句型結構線索、7–36 字長度、CEEC 覆蓋率至少 55%、殘留標記與易錯搭配，再評分。

| 評分項 | 分數 |
| --- | ---: |
| 目標字或變化形 | 24 |
| 句型結構線索 | 12 |
| 長度 | 5／11／16 |
| CEEC 覆蓋率 | 0／6／13／18 |
| 有順序的搭配句型吻合 | 14 |
| 因果、轉折等語境線索 | 最多 8 |
| 學習主題線索 | 4 |
| 辭典／母語者篩選來源 | 4 |
| 真人錄音 | 1 |
| 只是談論該單字本身 | 扣 25 |

通過基本檢查且 65 分以上才成為精選，畫面分數最高顯示 99。相同句合併時保留已有翻譯、錄音與作者標示；第二句在品質接近的候選中兼顧不同內容與來源，避免兩句幾乎一樣。FreeDictionaryAPI 與 Wiktionary 視為同一來源家族。

未達精選門檻但通過基本檢查者可當參考句；**硬性拒絕的句子不會再當作保底**。完全沒有合格句時只顯示「暫無合格例句」，不製造看似展示詞義的例句。

這是可解釋的規則評分，並非語言模型、完整句法分析或詞義消歧；分數不是文法正確率，也不能保證考試適用性。V5 的例句挑選方式保留；V5.1 擴充搭配知識庫，既有句型內容保留，來源標籤改為逐句核對。

近義詞改用 Datamuse `rel_syn`（WordNet 同義關係），再取 CEEC 交集；不同詞義、詞性及上下文仍須個別判斷，不能直接互換。參考 [Datamuse API](https://www.datamuse.com/api/)。

CSS 與 JavaScript 使用相對路徑；defer script 順序已處理依賴，請勿改成 async 或任意調換。沒有新增 CDN 前端框架。原版選用的 Transformers.js / MiniLM 只在使用者啟用 AI 時下載。

後續自行修改某個 CSS／JS 檔時，請同步更新兩個入口該檔 URL 的 `?v=` 值（任意新版本字串皆可），或讓主機對該檔重新驗證快取。建議主機讓 HTML 使用 Cache-Control: no-cache；本包不覆寫既有主機設定。

## 外部服務與測試範圍

原本的外部服務依賴仍在。Google 免金鑰翻譯端點不是具服務保證的正式 Cloud Translation API；受限時保留英文與內建中文。Datamuse 官方目前公告 **2027-01-01 起請求需 API key**，長期維護可透過自有後端代理接入；不要把私人 key 硬寫在公開前端。屆時受影響的近義詞／搭配補充不會清除收藏或內建詞表。[Datamuse 官方公告](https://www.datamuse.com/api/)

30 項流程測試通過；6,012 筆原始資料逐欄一致、795 條原有句型保留、收藏及使用者進度 key 一致；AI 衍生索引 key 因內容擴充而更新。此環境沒有可用瀏覽器，下載也受網路限制；未完成桌面／iPhone 實機視覺驗證、真人音檔播放、AI 模型完整下載，或第三方 API 的實際連線效能量測。請見 TEST_REPORT.md；無需執行測試即可部署。
