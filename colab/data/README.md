# 原創示範資料

`gsat115_style_examples.jsonl` 是參考使用者上傳的 115 學測英文試卷風格，新寫的 78 句例句，涵蓋 12 類文法與 CEEC 詞彙級別 1–6。`gsat_examples_demo.jsonl` 另含 60 句一般英文學習例句。這兩個檔案中的新寫句子、短詞義提示與標籤由本次工作產生，依 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 提供，可用於示範微調、修改與評估。

上述授權只針對這兩個原創示範資料檔；不涵蓋使用者上傳的考卷、原網站詞表或第三方模型。原始 PDF 沒有放進網站、筆記本或公開資料檔，也不會自動上傳。

欄位 `target_word` 是目標字的基本詞形；`target_forms` 列出示範句中可接受的實際詞形；`level` 是該字在現有 CEEC 詞表中的級別，並不等於整句難度。風格來源記錄於 `docs/GSAT_115_STYLE.md`。一般示範資料沒有 `grammar_tag` 時採 `auto`。

資料量很小，未經教師逐句評閱。它能驗證程式流程，不足以證明模型學測文法能力。正式訓練請使用有權利用、人工確認的資料，按目標字隔離訓練與測試，並檢查原文近似、詞義、搭配及指定句型。
