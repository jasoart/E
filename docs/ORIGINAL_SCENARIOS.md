# 原創情境句：全詞表練習

全部 6,024 個詞條至少有三個、最多十一個不同的原創英語情境句，每句 15–30 個英文詞，附繁中翻譯、句構說明、仿寫方向與題材。這些句子是本站編寫的仿學測語言練習，不是試卷原文、官方題目或上傳 Anki 句的改標。編寫時盡量使用學測常見的校園、家庭、社區、科學、健康、環境和資訊場景，讓前後文提供因果、對比或其他可辨認的字義線索。

| 指標 | 資料來源與解讀 |
| --- | --- |
| 官方原詞條 | 6,012 個原 ID，級別與釋意保留。 |
| 補充詞條 | 12 個，另行標示為本站補充。 |
| 基礎與擴充目標 | 每詞至少三個不同語境；擴充目標為十一句，各句實際含該詞或程式支援的詞形。未達標詞條列在缺口清單。 |
| 新增獨立句、採用獨立句、詞條顯示次數、缺口 | 以 [`authored_scenario_coverage.json`](../research/authored_scenario_coverage.json) 的生成統計為準；共用句可教多個詞，獨立句數與顯示次數分開計。 |

來源為 `research/authored_scenarios.txt` 與 `research/scenario-batch-*.txt`。每行五欄：英文、繁中翻譯、句構、仿寫方向、題材。生成器 `research/build_authored_scenarios.cjs` 同時可沿用既有專題中合格的自編句；只收 15–30 詞、有完整教學欄位、不是上傳原卡原句的例句。對應詞條時，使用完整單字或既有系統支援的實際詞形，不用子字串或相同字根猜詞；March／march 和上午／下午等歧義另設限制。生成器拒絕新編來源中的重複句，並以實際遮字匹配器再次驗證。

主要教學卡在找到三個不同原創語境後才切換。原上傳教材仍可展開備查，原釋意完整可見。新的遮字作答紀錄以來源及完整句子作識別，避免沿用另一句的舊成績；收藏與複習鍵則維持相容。

前端前三句分別做字義線索、句構與用法、閱讀與寫作延伸，其餘符合條件的情境接續顯示。這是學習方向，不表示每句都對應一個官方題型。句構說明和仿寫方向由來源檔逐句編寫；句中導讀的鄰近字與線索提示是學習輔助，不把簡單規則推論稱為人工逐句語法審定。另有獨立標示的 [Tatoeba 參考句](REFERENCE_SENTENCES.md)。

執行 `node research/build_authored_scenarios.cjs --check` 可確認產物與來源一致。`tests/notebook-all-words.cjs` 檢查全部詞條至少三句互異、實際目標詞形、完整雙語欄位、十一句目標的缺口及原教材備查；`python3 tools/check_site.py --suite all` 執行資料、程式和 Chromium 流程。自動檢查不能證明所有句子的語意、文化脈絡及教學效果已由外部專家審定。
