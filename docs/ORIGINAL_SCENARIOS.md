## 編寫與套用

來源為 `research/authored_scenarios.txt`，每行五欄：英文、繁中翻譯、句構、仿寫方向、題材。生成器 `research/build_authored_scenarios.cjs` 索引完整單字或既有系統支援的實際詞形，不使用子字串或僅有相同字根的字。March／march 與上午／下午等歧義另加限制。

只有找到兩個不同語境才替換主要練習；當場保留原教材物件，供完整釋意及原句備查使用。未補足的詞條維持原來源，不冒稱改寫完成。確切缺口見 `research/authored_scenario_coverage.json`。

新句用於搜尋、雙語情境卡、遮字作答與回想練習。收藏、複習鍵與原詞條 ID 保持相容；新句不承接舊句作答成績。詞性導讀也修正了把 `adv.` 當作 `v.`、把 `pron.` 當作 `n.` 的子字串判斷。

## 驗證

本機通過 146 項 JavaScript 測試、57 項 Python 測試及三套 Chromium 測試。瀏覽器驗證原創／待改寫篩選、原句備查、完整原釋意、搜尋、作答、收藏，以及 320／390 px 手機尺寸；自動外站請求為零。

生成資料檢查涵蓋目標詞出現、兩句互異、來源標記、原始資料保留及統計一致。這些檢查不等同於證明每句語義與文法已由外部專家審定。
