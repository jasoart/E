## 發音與效能的驗證界線

發音單元測試覆蓋多來源、口音、授權、署名、取消、快取、12 秒總預算及重複事件。瀏覽器使用受控 Commons 中繼資料與短測試音訊檢查實際播放和 UI；另一份測試刻意阻斷兩個公開來源檢查裝置備援。這些檢查不能證明外站錄音持續可用、真人錄音品質或 iPhone 相容。

本環境的真實字典查詢逾時，Commons 中繼資料遭代理 CONNECT 403。指定的部分研究網頁及 PDF 也受網路限制；可讀取的原始 GitHub 資料及未取得的全文均記錄於 [TECHNOLOGY_RESEARCH_2026.md](TECHNOLOGY_RESEARCH_2026.md)。

搜尋比較以每輪相同教材快照、獨立 Node 程序及 175 次未使用結果快取的查詢評估。延遲、冷建構、記憶體與較忙一輪的差異見 [SEARCH_PERFORMANCE.md](SEARCH_PERFORMANCE.md)；不能把 Node 數據直接當成手機瀏覽器成績。

GitHub Actions 工作流程已加入並在本機執行對應檢查；遠端執行結果須以 GitHub Actions 顯示為準。本輪未變更 Pages 部署設定，也未宣稱已在新雲端實例重新驗證。沒有學生延後測驗或學測分數實驗，因此不把程式檢查通過當成學習成效證明。
