「核心／延伸」是本專案對官方詞彙範圍的操作標籤，不是文件另列的官方能力級別。網站現有詞表的 6,012 個條目也不能直接當成官方常用 4,500 字範圍或全句難度認證；須確認詞表版本、詞形映射與實際語境中的字義。

## 官方要評量什麼

命題以 108 課綱普通型高中部定必修課程為範圍，評量基本核心能力；閱讀與寫作是現階段主要評量方向。（正文 p. 1、3／PDF p. 7、9）

| 官方測驗目標的組合 | 例句／教材可練習的部分 | 單句無法直接驗證的部分 |
| --- | --- | --- |
| 常用實詞的構詞、語意與搭配 | 同字不同義、詞形選擇、自然搭配、有線索的情境 | 沒有上下文時的篇章解讀 |
| 依文意掌握各類語詞及語法 | 時態、主動／被動、子句、詞組、轉折與因果的正確使用 | 跨句資訊對時態及詞義的限制 |
| 篇章組織與脈絡 | 主題句、細節句、轉承句的功能可分別標籤 | 段落排序、篇章填句、全文一致性 |
| 擷取、分析、比較與推理 | 明確指涉、資訊關係、可支持的局部推論 | 全文主旨、多則訊息整合、圖文判讀 |
| 依提示表達或回應 | 合乎語境的改寫、摘要句、詞形變化 | 閱讀後寫作是否忠於整篇資料 |
| 中譯英與引導寫作 | 正確、通順、達意的句子；單句／合句／複句 | 文章切題、細節支持、段落組織與整體連貫 |

以上目標來自正文 p. 1–2（PDF p. 7–8）；表中「例句可練習」與「無法直接驗證」是本專案的教學推論。

## 對目前資料、提示與評估的具體建議

以下是本專案的建議，**不是官方命題規定**。

1. 保留 `target_word`、字義、目標詞形與 `grammar_tag`；補足詞性與目標字義的人工確認。依已有 CEEC 級別標記核心（1–5）或延伸（6），未知級別則明列未知；不替未知詞強填等級。延伸例句保留作挑戰用途，不直接刪掉。
2. 每句只聚焦一項主要文法，另記語篇功能，如因果、讓步、時間、對比、目的、舉例或條件。真正的語篇銜接資料須包含前後文；孤立句中的 however 或 therefore 不能自證連貫。
3. 訓練核心先確保自然搭配、明確指涉、主謂一致、時態／被動、合理事件順序，再增加句法變化。比起堆疊艱深句型，這更符合基本核心能力的定位。
4. 單句提示可要求「自然使用目標字義，給出可理解的新情境，以高中常用字為主；只產生一個完整英文句子」。8–24 詞保留為產品預設，長度篩選只表示格式符合；需要較長句才能自然表達時，應另外設計可調長度模式。
5. 教學擴充以原創的中譯英句對與短情境為優先；篇章結構、混合題、圖文推論需獨立資料和評估，不能從單句模型成功推論它們已完成。中文翻譯也須人工確認，不把目標字義欄位當作整句翻譯。
6. 依目標詞／字義或相近情境分組留出評估，比較原模型、微調模型與量化匯出模型。分開記錄字義、搭配、文法、指涉／邏輯、自然度及核心／延伸適切性；規則通過與人工判定分開報告。
7. 跨年試卷只當私人分析與近似複製檢查來源；新撰資料記清楚來源、授權與人工審核狀態。示範集只能驗證流程，不能當成掌握學測程度的證據。

這次官方文件分析本身沒有執行 GPU 微調、模型產生評分或 iPhone 13 實機測試；它能修正生成目標與評估依據，不能證明模型已達到這些要求。
