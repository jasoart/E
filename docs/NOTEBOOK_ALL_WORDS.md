# 單字筆記 V2.0：全詞表教學設計

網站保留原有 6,012 個官方詞條 ID，另明確標示 12 個補充詞，共 6,024 個可查詞條。原詞表級別、完整中文釋意、上傳教材原句、收藏與複習紀錄保留。每個詞的主要練習提供三個 15–30 詞的原創英文情境句，各有繁中翻譯、句構說明、仿寫方向與題材。完成與獨立句數以 [`authored_scenario_coverage.json`](../research/authored_scenario_coverage.json) 的生成統計為準。

| 筆記欄位 | 提供的資訊與練習 |
| --- | --- |
| 字義與詞性 | 每詞顯示常用義、詞性、完整原詞表釋意及原雙語教材的簡要說明。原資料的少用義仍可查；需要時用編輯修正的常用義引導學習。 |
| 搭配與句構 | 展示有雙語來源的搭配或獨立文法句型；句中導讀圈出實際相鄰字、因果與對比線索，供學生核對。沒有獨立搭配時練完整例句，不把例句數算成搭配數。 |
| 近義辨析 | 專題筆記的近義比較直接顯示；WordNet 同義候選在字典展開區附英語詞義範圍，提醒檢查詞性、語境與搭配。缺乏明確依據時用三句對照，不捏造可互換近義字。 |
| 字族與詞形 | 只呈現專題教材或 WordNet 明示的派生關係。動詞過去式、過去分詞、第三人稱單數、V-ing、名詞複數與可比較形容詞的比較級分欄顯示；不規則形式和不可數、不可比較的情況另行處理。 |
| 情境句與仿寫 | 三個含目標詞實際詞形的原創語境，逐句附翻譯、句構說明、仿寫提示與原句線索；可遮字作答與回想。原上傳教材句保留於備查區，來源逐句標明。 |

全詞條資訊來自原雙語教材、399 組專題筆記、127 項逐詞編輯常用義／提醒與 Princeton WordNet 3.1 明示關係。生成資料對 6,024 詞都提供常用義、詞性與用法提醒；5,960 詞有 WordNet 英語詞義、1,695 詞有明示字族、3,469 詞有帶詞義範圍的英語字典近義候選、556 詞有獨立雙語搭配。這些欄位依據各詞可取得的資料呈現，沒有來源的字族、近義或搭配不硬填；英語字典詞義不自動翻成特定例句的中文義。692 詞有依據原教材或編輯資料的逐詞用法提醒；其餘 5,332 詞標示為通用「詞性學習提示」，不宣稱每詞都已完成個別研究。WordNet 節錄不是大考中心的考試詞頻或難度排名，詳見[資料授權](../assets/data/wordnet.NOTICE.txt)。

58 組功能詞有另列的文法句型，232 條句型和詞彙搭配分開計數。代名詞的主受格、所有格和反身形式不當作派生字族。`media`、`medium/media` 等原詞條變體仍保留各自 ID。`getCuratedExamNotebook` 回傳專題編輯資料，`getExamNotebook` 回傳全詞表筆記；未知 ID 回傳 null。

115 學年度起適用的英文考科說明涉及語意、構詞、搭配、篇章理解及讀寫。本站三句情境可練單句的詞義判斷、語意線索和仿寫；它們是本站原創練習，並非大考中心原題或已核定的能力分級。已上傳的 115 年試卷和考試說明只作題型與內容參照，短引文逐頁核對，沒有推定官方答案。

## 維護與驗證

專題筆記來源為 `research/exam_notebook.json` 和 `research/function_word_notes.json`。原創情境句來源為 `research/authored_scenarios.txt` 與 `research/scenario-batch-*.txt`，由 `research/build_authored_scenarios.cjs` 比對實際目標詞形後生成。逐詞常用義修正寫在 `research/vocabulary-editorial.json`，由 `research/build_vocabulary_enrichment.cjs` 與既有雙語教材、WordNet 節錄合併生成。修改來源後重建資料，再以 `python3 tools/validate_site.py --refresh-hashes` 更新兩個 HTML 入口的素材雜湊。

`tests/notebook-all-words.cjs` 逐詞檢查原句數、翻譯、句構、仿寫、遮字匹配及原上傳教材備查；`tests/vocabulary-enrichment.cjs` 和 `tests/inflections.cjs` 分別檢查常用義、明示字族／近義與詞形分類。Chromium 測試另檢查桌面、320／390px、來源標記、收藏、回想與音訊錯誤狀態。自動檢查不能替代全部句子的外部語言專家人工審稿。
