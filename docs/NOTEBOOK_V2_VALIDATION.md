## 驗證界線

Chromium 的發音檢查刻意中止外部字典請求，驗證裝置備援或無聲線時的可見狀態。發音單元測試使用模擬字典、媒體與聲線，涵蓋來源、授權、逾時、停止及換字取消；這些結果不代表已完成真人錄音、iPhone 實機或裝置聲線音質驗證。

實際 DictionaryAPI 連線被目前雲端網路政策拒絕（proxy CONNECT 403）。啟用設定中的 `api.dictionaryapi.dev`、`upload.wikimedia.org` 後須重試實際錄音；不需要 API 金鑰。靜態網站、本機資料、搜尋及學習功能不依賴這兩個網域。
