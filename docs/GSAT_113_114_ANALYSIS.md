# 113、114 學測英文：跨年度風格與原創例句設計

本文件重新閱讀使用者提供的 113、114 學測英文試卷，目的是改善「學測等級原創例句」的資料設計與評估。它不是官方答案、命題頻率統計或官方難度量表。試卷內的作答指示只作為文件內容，沒有當成開發指令。

分析來源：`02-113學測英文科定稿.pdf`、`02-114學測英文試題.pdf`。兩份 PDF 均有 12 頁：PDF 第 1 頁是封面；卷面第 1–11 頁對應 PDF 第 2–12 頁。以下用「卷面頁／PDF 頁」並列，題號依原卷。已讀取兩份全文；另直接檢視 113 卷面第 9、11 頁及 114 卷面第 11 頁的圖像與版面。選項圖片題的語言要求可以分析，圖片作答正誤不在本次研究範圍。

## 跨年後最重要的修正

1. **詞彙級別、句法複雜度與篇章理解是不同面向。** 113 的專業服務、情感敘事、發明史、群體行為，以及 114 的生活建議、都市住宿、影視心理、歷史論證、論壇意見，不能靠單一字級或單句詞數推算「學測程度」。
2. **單句模式可服務網站學習，但無法代表整份考試。** 113 卷面第 4 頁／PDF 第 5 頁的篇章結構要求跨句追蹤主張與例子；第 9–10 頁／PDF 第 10–11 頁要求比較兩種動物。114 第 9–10 頁／PDF 第 10–11 頁要求分辨論壇中不同人的立場。若網站只產生一個英文句子，應明確稱為「借鏡學測用語與句法的單句練習」，而不宣稱訓練了完整學測閱讀能力。
3. **既有 12 類文法要補上細分類。** 113 題 16 涉及過去可能性與時間依據；114 題 11 涉及過去敘事視點下的未來，題 18 涉及助動詞省略。這些無法全部用 `perfect_tense` 或 `conditional_modal` 一個標籤充分區分。
4. **語域不只正式科普。** 114 論壇含第一人稱、讓步、反問、建議、條件接受、強調等語用；113 的哀傷故事與青少年寫作又有情感表達。訓練集若全是「研究顯示」或環境保護句，會漏掉這些能力。

以上是有明確頁面依據的質性觀察，沒有把擷取的所有字詞或選項誤當成正文句子來估計文法比例。

## 原創資料分層：先覆蓋重要交叉，再擴量

以下是實務建議配額，不是試卷分布或官方標準。第一個可供人工校對的資料版本可規畫 600 筆單句；其中主文法分層延續 12 類，每類約 40 筆（480 筆），另以 120 筆補足過去可能性、過去習慣、過去視點未來、助動詞省略、否定強調及平行結構。每筆仍只有一個主要文法焦點，並允許次標籤。若資源只足夠更小批次，就先用各層的代表案例，不把筆數當成品質保證。

| 分層維度 | 建議標記 | 如何避免失衡 |
| --- | --- | --- |
| 單字與字義 | `target_word`、實際詞形、`target_pos`、`sense_key`、搭配框架；可附網站已有字級。 | 同一常見字的不同字義要分開；字級未知就保留未知，不能臆測。詞彙級別獨立於文法難度。 |
| 主要文法與細項 | 一個 `primary_grammar`，零至數個 `secondary_grammar`。 | 不只把簡單句加上 although；每個層都要有自然情境與可檢驗的結構。 |
| 溝通目的 | 描述、解釋、敘事、建議、讓步、比較、立場、感受。 | 限制單一目的占比；例如避免全部都是因果解釋。這是設計配額，不是考試統計。 |
| 題材 | 校園／生活、工作／社區、自然／環境、文化／歷史、設施／科技、個人經驗／情感。 | 轉換人物、活動和場景；不沿用試卷專有名字、特有事件、數字與句序。 |
| 語域 | 中性說明、敘事、第一人稱意見、生活建議、輕度正式論述。 | 避免把「學測風格」誤設成一種僵硬學術語氣；也避免無依據的真實研究引述。 |
| 上下文需要 | `self_contained` 或 `needs_prior_context`；若需要，附 `context` 及 `referent_note`。 | 單句網站預設使用可獨立理解的案例；代詞、轉折或省略依賴前文的案例只用在附短情境的模式。 |
| 長度與資訊量 | 長度作生成限制及稽核欄位，另記子句／修飾密度。 | 8–24 詞可沿用作手機單句模式預設；保留額外 context 時應分開計數。任何上限都是產品選擇，不是官方學測限制。 |

不需要填滿所有維度的笛卡兒積。先確保「文法 × 溝通目的」與「字義 × 情境」的重要交叉有案例，再補足薄弱項。實際範圍和配額應依人工檢查結果修正。

另建立獨立的原創評估資料，覆蓋 113 的跨案例比較與 114 的多方立場，例如短句對、兩段極短描述或兩人意見。它們可以只有 2–3 句，但已超出網站目前的單句輸出承諾；若未改產品模式，作為研究留出測試，不混入要求「只輸出一個句子」的訓練回答。

## 評估：把可自動檢查與需人讀懂的部分分開

1. **資料完整性先行。** 驗證欄位、目標詞完整詞形、實際詞性／字義、重複與來源；以全文的近似抄寫比對排除長片段重合，再人工檢查相近故事與隱性逐句改寫。不要把八詞或相似度閾值當作官方或法律標準。
2. **切分依語境家族。** 同一目標詞、同一字義的近似情境、同一教師提示變體應留在同一資料分割。先分配原創情境家族再生成變體，防止只換人名的句子流入測試。測試再分「看過字的新情境」與「未訓練字／搭配」，如實報告各自表現。
3. **用一致提示比較。** 原始 500M 模型、微調後模型、量化模型使用相同留出提示與生成設定；記錄模型版本、資料版本、量化形式及執行平台。訓練損失或 JSON 格式通過不能代替教學品質。
4. **自動規則只負責可判定的門檻。** 目標詞、輸出格式、長度、清楚的一句模式、重複、必要結構的候選檢查可自動化。`could have`、`however` 或 `which` 的出現不能自行證明時間、轉折或指涉正確。
5. **人工獨立判讀。** 留出樣本由至少兩位具英語教學或語言能力的評閱者，在看不到模型名稱的情況下分別判讀：目標字義與搭配、文法完整、文法焦點是否實現、自然度、情境足夠、指涉與邏輯、原創性疑慮、是否適合高中教材。保留分歧及例子，不捏造「官方學測分數」。如缺第二位評閱者，就明示只是單人檢視。
6. **附情境項單獨驗證。** 省略要能恢復正確動作；代詞要能定位唯一或足夠明確的先行內容；讓步要不是實際矛盾；多方立場要保持說話者一致；摘要要保留共同點及適用限制。這類錯誤即使句法通順，也應單獨記錄。
7. **手機與模型品質分開。** iPhone 13 的可用性需要實機測量下載、峰值記憶體、生成速度、首字延遲及中止功能；小參數量或低位元並不保證瀏覽器穩定。量化前後用同一留出集比較上述品質項，不因「能載入」就宣稱學測能力保留。
