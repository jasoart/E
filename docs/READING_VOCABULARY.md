# 111–115 閱讀詞彙擴充

本次依使用者提供的五份學測英文試卷整理 **970 個既有詞條的閱讀證據**，並新增 **80 個原詞表以外的題材補充詞**。其中 137 個既有詞條另附人工整理的語境義、閱讀提醒與共 144 組學習搭配。原有詞條 ID、完整釋義、收藏及複習資料保留。

## 如何使用

1. 開啟「閱讀詞彙」，按年度、主題、題型及複習順序篩選；原詞表級別與搜尋也會同時生效。
2. 左側列出既有詞條，單字卡新增「111–115 閱讀詞彙」：顯示實際詞形、題組、試卷／PDF 頁碼，以及已整理的閱讀義。閱讀義有自己的核對題組，其他出處不自動套用相同意思。
3. 展開「閱讀題材補充詞」查看 80 個新詞的詞性、中文義、閱讀提示與出處。這批詞另作題材準備，不冒稱官方 6,012 詞，也不計入已有 V2 三句覆蓋；因此不套用原詞表 L1–L6 篩選。
4. 「匯出目前詞單 CSV」依目前條件匯出兩類詞，保留詞條類型、原釋義／補充釋義、語境義範圍、年份、題組、詞形與頁碼。全站搜尋命中補充詞時，亦可從提示直接開啟該區。

六個主題為文化歷史與地理、科學健康與心理、科技發明與設計、自然生態與永續、社會生活與消費、人物經歷與探索。

新補充詞包含 affordable、archipelago、retina、synesthesia、zebrafish、vegan、plant-based、cost-effective、empathy、transplantation 等；逐詞釋義及提示維護於 [reading_supplemental.json](../research/reading_supplemental.json)。

三個優先層級是工程與教學整理規則：

- **跨年重點**：至少在兩個不同年度的正文中有詞形證據；既有清單共 246 詞。
- **篇章常用**：未達跨年條件，但出現在至少兩個題組，或已有逐篇編寫的閱讀義。
- **主題詞彙**：其他已核對的正文詞形；新增題材詞同樣依其實際年度區分跨年或主題。

這是歷屆出現與複習順序，不是未來出題機率。單篇重複某個題材詞不等於跨年常考；學習搭配可整理為原形，並不宣稱每組都是試卷逐字引文。

## 來源與核對

五份附件的 SHA-256、版本、12 頁頁數及每個正文起訖位置保存於 [語料清冊](../research/reading_corpus_manifest.json)。共核對 25 個正文單位：15 個閱讀測驗題組、5 個混合題正文、5 個篇章結構正文，合計 8,229 個 Latin 詞形 token；這不是 8,229 個不同單字。

以逐篇起訖錨點切分正文，排除題幹、選項、頁首頁尾、論壇說話者標籤及地圖商店標籤；篇章結構保留原空格，不補入選項答案。111／113 的雙欄順序及 115 混合題跨 PDF 第 10–11 頁均已核對。試卷紙本頁碼比 PDF 頁碼少 1，因 PDF 第 1 頁為封面。

詞形映射優先使用詞條所列形式與有詞性依據的屈折變化；同形歧義沒有逐篇編輯依據時跳過。`stationed` 的動詞用法另作明確人工核對；`alternative-meat` 等複合詞只有在編輯逐篇確認時才連結其成分，畫面保留整個原詞形並標示「含複合詞成分」。派生字族不會自動全部算作出題證據。

原始 PDF 和完整擷取正文只作私人核對材料，不提交 repository。公開來源檔是沒有原句次序的逐頁詞形／次數清冊及短定位錨點；網站載入的是詞條、提示和必要定位資訊。

## 維護與驗證

```sh
# 使用私人 PDF 重驗附件指紋、正文邊界、逐頁詞形與雜湊。
python3 research/extract_reading_corpus.py --check --pdf-dir <私人PDF目錄>

# CI 無需私人附件；檢查已提交清冊及確定性的生成結果。
python3 research/extract_reading_corpus.py --check
node research/build_reading_vocabulary.cjs --check
python3 tools/check_site.py --suite all
```

閱讀義修改 `research/reading_editorial.json`；新題材詞修改 `research/reading_supplemental.json`；重新執行生成器後更新兩個 HTML 的素材雜湊。生成器會拒絕缺少正文證據的詞形、不存在的詞條／題組 ID，以及重複既有詞條或其列出形式的「新」補充詞。

測試逐筆核對所有詞形的來源、年度與頁碼，並測試跨條件同篇交集、語境義搜尋、兩類 CSV、補充詞獨立篩選、320／390 px 排版、鍵盤與減少動態效果，以及原收藏和複習資料相容性。這次內容擴充的驗證不沿用前一版搜尋速度測量作新成績。

2026-10-26 完整驗證結果：`tools/check_site.py --suite all` 回傳 0；160 項 JavaScript、63 項 Python、八個生成／來源檢查、網站素材驗證與六組 Chromium 流程全部通過。另以五份實際附件重驗 PDF 指紋、正文邊界及詞形清冊通過。測試中的外部音訊刻意阻擋，未量測外站即時可用性或 iPhone 實機聽辨。
